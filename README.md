# arrear-bill

নবম পে-স্কেল (জাতীয় বেতনস্কেল ২০২৬) — গেজেটেড কর্মকর্তার বকেয়া বেতন বিল tool (টি.আর. ফরম ১৩)।

**ব্যবহার করুন:** https://sumonbakar.github.io/arrear-bill/

- পে-ফিক্সেশন বিবরণী থেকে ৩০-০৬-২০২৬ এর মূল বেতন, ২০১৫ স্কেলের গ্রেড ও নতুন গ্রেড দিলে আইবাস++ এর নিয়মে নতুন মূল বেতন নির্ধারণ হয়।
- মূল বেতনের কোড ৩১১১১০১ (অফিসার); বিশেষ সুবিধা (৩১১১৩৫২) ও বাড়ি ভাড়া (৩১১১৩১০) সমন্বয় স্বয়ংক্রিয়।
- বিল, মাসওয়ারি বকেয়া বিবরণী ও হিসাবরক্ষণ অফিসের পৃষ্ঠা — PDF ডাউনলোড বা প্রিন্ট করা যায়।
- বেতন স্কেল: এস.আর.ও. নং ৩৪৭-আইন/২০২৬ (১৭ সেপ্টেম্বর ২০২৬) এর তফসিল অনুযায়ী।
- সব তথ্য শুধু ব্যবহারকারীর নিজের browser-এ থাকে, কোথাও পাঠানো হয় না।

জমা দেওয়ার আগে নিজের বেতন নির্ধারণী বিবরণী ও হিসাবরক্ষণ অফিসের নির্দেশনার সাথে মিলিয়ে নিন।
